# Heart Disease Risk Prediction

## Overview
This project analyzes various health metrics to predict the risk of heart disease.

## Dataset
The dataset includes the following key features:
- **Patient Information:** Age, Gender, Height (cm), Weight (kg), BMI
- **Lifestyle Factors:** Smoking, Alcohol, Physical Activity, Stress Level
- **Medical Measurements:** Max Heart Rate, Oxygen Saturation, Resting ECG, Exercise Angina, ST Depression
- **Symptoms:** Chest Pain Type

1. **Data Loading:** Importing the dataset using pandas.
2. **Data Exploration:** Analyzing the structure and summary statistics of the data.
3. **Data Preprocessing:** Handling missing values and encoding categorical variables.
4. **Model Training:** Building a predictive model.
5. **Evaluation:** Assessing the model's performance.
